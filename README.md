# 💰 Expense Tracker

A simple full-stack Expense Tracker web application built using open-source technologies.

The application allows users to record their income and expenses, view transactions, delete transactions, and automatically calculate their total income, total expenses, and current balance.

## ✨ Features

- Add income transactions
- Add expense transactions
- View all transactions
- Delete transactions
- Calculate total income
- Calculate total expenses
- Calculate current balance
- Store data using SQLite
- REST API using Flask
- Responsive frontend
- Open-source under the MIT License

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### Database
- SQLite
